How erasure works

Just type the value. You don't need to say what kind of data it is. Every stored value has a keyed fingerprint (HMAC-SHA256); the same fingerprint is computed from what you type and every matching copy is deleted across all sessions. Nothing is decrypted to find it, and formats don't matter: +91 98765-43210 and 9876543210 match.

After erasure, old tokens in past replies show as [REDACTED].

End this session

Admin sign in

Only administrators can see which real value sits behind each token. Every value you reveal is recorded in the audit log under your name.

First run? The password is printed in the terminal where you started the app, or set your own with ADMIN_PASSWORD in .env.
