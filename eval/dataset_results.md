# VaultAI detection results: dataset.jsonl

Test set: 460 sentences, 591 labelled PII spans, 140 hard-negative sentences (order IDs, invoices, prices, versions, checksum-invalid 12-digit numbers). Strict match: type + exact span.

## Ablation: what each layer adds

| Configuration | Precision | Recall | F1 | Hard negatives wrongly flagged |
|---|---|---|---|---|
| Regex only | 84.4% | 66.8% | 74.6% | 61/140 (44%) |
| + checksums | 95.2% | 66.8% | 78.5% | 19/140 (14%) |
| + context words | 99.8% | 79.4% | 88.4% | 0/140 (0%) |
| + spaCy NER + name list (full) | 99.5% | 97.6% | 98.5% | 0/140 (0%) |
