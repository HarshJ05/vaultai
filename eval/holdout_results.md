# VaultAI detection results: holdout.jsonl

Test set: 420 sentences, 544 labelled PII spans, 120 hard-negative sentences (order IDs, invoices, prices, versions, checksum-invalid 12-digit numbers). Strict match: type + exact span.

## Ablation: what each layer adds

| Configuration | Precision | Recall | F1 | Hard negatives wrongly flagged |
|---|---|---|---|---|
| Regex only | 79.0% | 53.9% | 64.0% | 66/120 (55%) |
| + checksums | 93.0% | 53.9% | 68.2% | 21/120 (18%) |
| + context words | 99.2% | 70.0% | 82.1% | 2/120 (2%) |
| + spaCy NER + name list (full) | 94.8% | 98.2% | 96.5% | 2/120 (2%) |
